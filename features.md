# Features #

1. Appointment calendar
2. Client list
3. Record sales/invoices
4. Quickview upcoming



Appointment details
- Summary
    - Date/time
    - Location
    - Customer name/contact
    - Service list (can add multiple)
        - Item - one
        - Staff - one
        - Duration
        - Resource (room/equipment) - multiple
        - Price
    - Pencilled in/confirmed
- Notes
- Sales/Invoicing
    - Total amount
    - Add deposit/promo code
- Recurrence
- System logs
- Actions
    - Confirm
    - Decline
